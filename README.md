## 📌 About This Repository

This repository contains a collection of **10 progressively challenging HTML webpages** created to build a strong foundation in webpage structure, semantic HTML, forms, navigation, multimedia, interactive elements, and specialized HTML5 features.

Instead of practicing individual elements in isolation, each task combines multiple concepts into a complete webpage based on a realistic scenario.

The complexity increases throughout the collection — from structured articles and forms to large, feature-rich webpages containing navigation systems, multimedia, embedded resources, image maps, interactive elements, and complex forms.

---

## 🎯 Learning Goals

The main focus of this collection is to develop the ability to:

| 🎯 Goal | 📖 Focus |
|---|---|
| 🧱 Structure | Build complete webpages with proper HTML structure |
| 🧩 Semantics | Use meaningful semantic HTML elements |
| 🧭 Navigation | Create internal and external navigation systems |
| 📊 Data | Organize information using tables and lists |
| 📝 Forms | Build structured forms with different input types |
| 🖼️ Media | Integrate images, audio, video and external content |
| ⚡ Interaction | Use HTML elements that provide basic interaction |
| ♿ Accessibility | Use meaningful labels, `alt` text and semantic structure |
| 🔬 HTML5 | Explore specialized and lesser-used HTML5 elements |
| 🏗️ Composition | Combine multiple concepts into complete webpages |

# 📌 Repository Philosophy

These webpages are intentionally **learning-focused rather than production-ready projects**.

The goal is to build the foundation first:

```text
HTML
  ↓
CSS
  ↓
JavaScript
  ↓
Frontend Projects
```

The individual exercises do not need to be highly polished products.

They exist to:

- 📚 Document the learning process
- 🧠 Reinforce concepts through practice
- 🛠️ Develop practical implementation skills
- 📈 Show progression over time
- 🧱 Build a strong foundation for larger projects

More polished and selective projects will come later when HTML, CSS and JavaScript are combined.
